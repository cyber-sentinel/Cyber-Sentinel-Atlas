# Ingestion Policies

This directory contains versioned governance for source acquisition, implementation authorization, change detection, inventory guardrails, validation, and review.

Policies define when an ingestion path is permitted to move from source evidence toward canonical candidate content. They do not authorize public redistribution or release by themselves.

Inventory thresholds are source-specific and evidence-driven. ATLAS does not use one global shrink/growth threshold as a substitute for provider/version-aware completeness checks.
