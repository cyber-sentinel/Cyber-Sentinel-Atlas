# Atlas Ingestion Foundation

This tree contains version-controlled implementation assets for the Phase 5.3 ingestion control plane.

Phase 5.3.1 is contract/framework work only. No live source ingestion is present.

Subdirectories separate source profiles, connector manifests, parser definitions, normalizer definitions, mapping profiles, policies, and authoritative inventory definitions. Ingestion artifacts are not canonical `AtlasRecord` records.
